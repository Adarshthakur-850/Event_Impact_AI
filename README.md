## 🚀 Project Overview

Event Impact AI is a Machine Learning project designed to analyze and predict the impact of various events using historical data, AI models, and analytical techniques. The system helps identify patterns, understand event influence, and generate intelligent insights for decision-making.

This project can be applied in areas such as:

* Social Media Trend Analysis
* Business Event Forecasting
* Marketing Campaign Analysis
* Public Sentiment Monitoring
* Real-Time Event Prediction
* Data-Driven Decision Support

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Adarshthakur-850/Event_Impact_AI.git
```

Move into the project directory:

```bash
cd Event_Impact_AI
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate virtual environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

Run the application:

```bash
python app.py
```

Or open Jupyter Notebook:

```bash
jupyter notebook
```
